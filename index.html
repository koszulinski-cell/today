How the numbers work

We don't make up numbers.

TODAY displays information from publicly available datasets. Every number is accompanied by its source and the date of the underlying data.

If a source does not provide current information, TODAY will say so instead of presenting an estimate as a live count.

About this project

TODAY is an independent data project designed to make government enforcement activity easier to understand.

The project does not claim to have information that government agencies or research organizations have not yet published.

TODAY is an independent data project. It is not affiliated with the U.S. government, ICE, Mapping Police Violence, or the Deportation Data Project.
